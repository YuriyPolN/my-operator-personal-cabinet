# Дипломный проект по программе «Системный аналитик: расширенный курс»

### Проектирование MVP личного кабинета сотового оператора «Мой оператор связи»

Репозиторий содержит комплект аналитической и технической документации для разработки базовой версии (MVP) мобильного приложения личного кабинета абонента.

* Бизнес-требования: **[SRS_My_Operator_Polishchuk.pdf](./SRS_My_Operator_Polishchuk.pdf)** — утвержденная Спецификация требований к ПО (ТЗ) со сквозной трассировкой.
